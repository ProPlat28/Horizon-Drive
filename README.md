# 🏎️ Horizon Drive

**Made by d4shy and ProPlat.** A 3D open-world driving and racing game in your browser.

👉 **[Play Horizon Drive](https://proplat28.github.io/Horizon-Drive/)**

- **Modes:** race the AI, or free roam (drive, fly, walk, enter buildings)
- **17 maps:** cities, coasts, islands, canyons, mountains, farms, desert, snow, a volcano, plus the original City and Campaign
- **Extras:** garage upgrades, nitro, day/night, traffic, minimap, Low/Medium/High graphics
- **Controls:** WASD drive · Shift nitro · F get in/out · N fly · Tab map · Esc pause (all changeable in Settings)
