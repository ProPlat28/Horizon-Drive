# 🏎️ Horizon Drive

**Made by d4shy and ProPlat.**

Horizon Drive is a 3D open-world driving and racing game that runs directly in the browser.

Explore large environments, race against AI opponents, customize your car, discover different maps, and freely drive around the world.

## 🎮 Play the Game

👉 **[Play Horizon Drive](https://proplat28.github.io/Horizon-Drive/)**

## 🗺️ Maps

Every map has its own hand-designed layout, terrain, towns and landmarks.

**Classic**

- Neon Harbor: downtown towers, a harbour and a ring road
- Palm Coast: beach towns along a long seaside road
- Pine Hollow: a twisty rally road through deep forest and lakes
- Red Mesa: narrow red canyons between mesas
- Meadowbrook: farms, fields, windmills and villages
- Frostfall: snowy mountain valleys and chalet villages
- Ember Isle: a ring road around a smoking volcano
- City: the original city with its ring road, downtown plaza, river bridges and mansion
- Campaign: the original campaign world, open countryside with no buildings

**Large**

- Azure Archipelago: seven islands joined by long bridges
- Sierra Pass: green valleys under snowy peaks and lakes
- Golden Dunes: open desert, dunes and an oasis town
- Riverlands: farmland split by a winding river

**Huge**

- Grand Metropolis: a huge city with suburbs, a highway and a harbour
- Great Canyon: endless canyon roads and desert outposts
- Endless Coast: a 30 km coastline of beaches and hills
- Polar Expanse: frozen lakes and remote research outposts

## 🎮 Controls

| Action | Default Key |
|---|---|
| Accelerate | W / Arrow Up |
| Reverse | S / Arrow Down |
| Steer Left | A / Arrow Left |
| Steer Right | D / Arrow Right |
| Nitro | Shift |
| Reverse Camera | B |
| Camera View | V / C |
| Enter / Exit Vehicle | F |
| Toggle Flying | N |
| Fly Up | Q |
| Fly Down | E |
| Map | Tab |
| Day / Night | L |
| Pause | Escape |

Controls can be customized from the Settings menu.

## ✈️ Flying Mode

Horizon Drive includes a flying mode that allows the vehicle to leave the ground and fly around the map.

Flying can be enabled using the flying toggle and controlled with the flying controls.

## 🌙 Day & Night

The world supports a day/night cycle.

Night mode changes things such as:

- Sky
- Fog
- Lighting
- Vehicle headlights
- Street lights
- Environment lighting

## 🚦 Traffic

The world contains AI traffic vehicles that drive around the roads.

Traffic can be enabled or disabled in the settings.

## 🚶 Pedestrians

The game contains pedestrians that populate areas such as:

- Parks
- Markets
- Roadsides
- Cities

Pedestrians can be enabled or disabled in Settings.

The game supports multiple camera options:

- Third-person camera
- Reverse camera
- Cockpit camera
- Mouse camera control
- Camera zoom

The cockpit view also includes a dashboard and steering wheel.

## 🗺️ Minimap

The minimap helps the player navigate the world and follow race routes.

It can be enabled or disabled from Settings.

## ⚙️ Settings

The Settings menu contains options for:

- Sound volume
- Nitro sound
- Pedestrians
- Traffic
- Minimap
- Speed display
- Control display
- Camera behavior
- Night mode
- Graphics quality: Low (original look), Medium, High
- Old sounds (the original engine sound)
- Custom keybinds

Game settings and controls are saved using browser storage.
