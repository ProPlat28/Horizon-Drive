# 🏎️ Horizon Drive

**Made by d4shy and ProPlat.**

A 3D open-world driving and racing game that runs in your browser.

👉 **[Play Horizon Drive](https://proplat28.github.io/Horizon-Drive/)**

## Modes

- **Race:** pick a map, laps, opponents and difficulty, then race the AI.
- **Free Roam:** drive, fly, walk around and enter buildings.

## Maps

| Size | Maps |
|---|---|
| Classic | Neon Harbor, Palm Coast, Pine Hollow, Red Mesa, Meadowbrook, Frostfall, Ember Isle, City, Campaign |
| Large | Azure Archipelago, Sierra Pass, Golden Dunes, Riverlands |
| Huge | Grand Metropolis, Great Canyon, Endless Coast, Polar Expanse |

Each map has its own layout: cities, coasts, islands, canyons, mountains, farms, desert, forest, snow and a volcano.

## Features

- Garage: paint, wheels, spoiler, engine, tyres, neon
- Nitro, flying mode and day/night
- Traffic, pedestrians and enterable buildings
- Minimap, full map and several camera views
- Graphics: Low (original look), Medium, High
- New or old engine sounds

## Controls

| Action | Key |
|---|---|
| Drive / reverse | W / S or ↑ / ↓ |
| Steer | A / D or ← / → |
| Nitro | Shift |
| Get in / out | F |
| Fly (up / down) | N (Q / E) |
| Cockpit view | V |
| Reverse camera | B |
| Map | Tab |
| Pause | Esc |

All controls can be changed in Settings.
