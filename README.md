# 🏎️ Horizon Drive

Horizon Drive is a 3D open-world driving and racing game that runs directly in the browser.

Explore large environments, race against AI opponents, customize your car, discover different maps, and freely drive around the world.

Made by d4shy and ProPlat

## 🎮 Features

- 🏁 Race against AI opponents
- 🌎 Large 3D open-world environments
- 🚗 Free Roam mode
- 🗺️ Multiple maps
- 🏎️ Customizable vehicles
- 🔧 Garage and vehicle upgrades
- 💨 Nitro system
- ✈️ Flying mode
- 🌙 Day/night system
- 🚦 Traffic vehicles
- 🚶 Pedestrians
- 🏠 Enterable interiors
- 🏙️ Cities and buildings
- 🛣️ Highways and race tracks
- 🌲 Procedurally generated scenery
- 📍 Minimap
- 🎥 Multiple camera modes
- 🎵 Sound effects
- ⚙️ Customizable controls and settings

## 🏁 Game Modes

### Race

Choose a map, number of laps, opponents, and difficulty before starting a race.

### Free Roam

Explore the world without having to follow a race.

Drive around cities, roads, highways, parks, buildings, and other areas.

## 🎮 Controls

| Action | Default Key |
|---|---|
| Accelerate | W / Arrow Up |
| Reverse | S / Arrow Down |
| Steer Left | A / Arrow Left |
| Steer Right | D / Arrow Right |
| Nitro | Shift |
| Reverse Camera | B |
| Camera View | V / C |
| Enter / Exit Vehicle | F |
| Toggle Flying | N |
| Fly Up | Q |
| Fly Down | E |
| Map | Tab |
| Day / Night | L |
| Pause | Escape |

Controls can be customized from the Settings menu.

## ✈️ Flying Mode

Horizon Drive includes a flying mode that allows the vehicle to leave the ground and fly around the map.

Flying can be enabled using the flying toggle and controlled with the flying controls.

## 🌙 Day & Night

The world supports a day/night cycle.

Night mode changes things such as:

- Sky
- Fog
- Lighting
- Vehicle headlights
- Street lights
- Environment lighting

## 🚦 Traffic

The world contains AI traffic vehicles that drive around the roads.

Traffic can be enabled or disabled in the settings.

## 🚶 Pedestrians

The game contains pedestrians that populate areas such as:

- Parks
- Markets
- Roadsides
- Cities

Pedestrians can be enabled or disabled in Settings.

## 🎥 Camera

The game supports multiple camera options:

- Third-person camera
- Reverse camera
- Cockpit camera
- Mouse camera control
- Camera zoom

The cockpit view also includes a dashboard and steering wheel.

## 🗺️ Minimap

The minimap helps the player navigate the world and follow race routes.

It can be enabled or disabled from Settings.

## ⚙️ Settings

The Settings menu contains options for:

- Sound volume
- Nitro sound
- Pedestrians
- Traffic
- Minimap
- Speed display
- Control display
- Camera behavior
- Custom keybinds

Game settings and controls are saved using browser storage.
